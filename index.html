État de l'application

Interface ALSF active. Les données des effectifs sont actuellement enregistrées dans le stockage local de ce navigateur.

Hiérarchie actuelle

ALPHA est la catégorie la plus élevée, suivie de BÊTA, GAMMA et DELTA. Dans chaque catégorie, le numéro 1 est le rang le plus élevé. Chaque rang précis ne peut être occupé que par un seul membre.

Stockage des données

Cette version utilise le stockage local du navigateur. Les données ne sont donc pas automatiquement partagées entre plusieurs appareils ou plusieurs utilisateurs. Une future synchronisation nécessitera un serveur ou une base de données.
